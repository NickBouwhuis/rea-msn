Windows Live Messenger 8.1, rebuilt for macOS and Ubuntu

A native reimplementation of the 2007 Messenger client. It signs in to Escargot, the community-run MSN service, and takes Messenger's look, emoticons and sounds from an installer you already have.

Free and open source. Nothing from Microsoft is included.

Get started

rea-msn ships no Microsoft code, artwork or sounds. You import them from Escargot's copy of the original installer, so the app looks the way you remember.

  1. Install the app

    Open the DMG and drag Messenger to Applications, or install the .deb for your Ubuntu release. The first time you open it on a Mac, allow it under System Settings › Privacy & Security.

  2. Get the installer

    Download the Windows Live Messenger 8.1 installer (escargot-wlm-8.1.0178-en.msi) from Escargot, and create an Escargot account if you don't have one.

  3. Import and sign in

    Run the importer on the installer, then sign in as yourname@escargot.chat: your Escargot username, not the e-mail address you registered with.

On macOS, after brew install sevenzip ffmpeg

/Applications/Messenger.app/Contents/Resources/import/Messenger/scripts/import-wlm-assets.sh \
    ~/Downloads/escargot-wlm-8.1.0178-en.msi

On Ubuntu

sudo apt install ./wlm-messenger_*.deb
wlm-messenger-import ~/Downloads/escargot-wlm-8.1.0178-en.msi

Everything you need for a day of chatting. The rest needs Messenger's peer-to-peer protocol, which isn't built yet.

How it was rebuilt

The client's behaviour and look come from the original binaries, decompiled with rea and Ghidra, and checked against the open-source Escargot server.

Signing in
MSNP15 with Passport tokens and the MBI key exchange, an HMAC-SHA1 and triple-DES blob built exactly as msidcrl40.dll builds it.
The challenge
The client's product key is hidden in msnmsgr.exe behind an XOR mask; the challenge routine was ported from the decompiled code.
The look
Messenger draws its windows from data in msgsres.dll: layouts, stylesheets and images in a custom run-length format. A ported decoder turns them into the skin both apps use.
Emoticons
A 32-bit image strip plus a table of animation strips, frame counts and play-once flags, stepped every 250 ms like the original.

Build it yourself

Swift on both platforms: a shared protocol library, a SwiftUI app for macOS and a GTK 4 app for Linux. A Docker image of the Escargot server lets you test against your own machine.

git clone https://github.com/NickBouwhuis/rea-msn.git
cd rea-msn

macOS (Xcode or Swift 5.10+)

cd Messenger
./scripts/build-app.sh
open build/Messenger.app

Ubuntu (Swift, libgtk-4-dev)

linux/scripts/install.sh
wlm-messenger

See the README for tests, the local server and how releases are built.
